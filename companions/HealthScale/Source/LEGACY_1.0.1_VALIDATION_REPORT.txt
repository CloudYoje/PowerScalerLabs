HEALTHSCALE 1.0.1 VALIDATION REPORT
===================================

SCOPE
-----
Health-only source tree. No PowerScaler Studio, Saga Workshop, lore/package,
discovery, Runtime Camera, Project Perception, Ki/stamina, or combat-scaling
systems are present.

LIVE-RATIO CONTRACT
-------------------
1. Each distinct maximum-HP change starts from the live pre-change ratio:
       current HP / maximum HP
2. A historical domain lease cannot override that ratio.
3. Maximum changes that occur while the same correction is still pending remain
   one staged transition and carry the pending ratio.
4. Transition damage/healing after the snapshot is applied as a delta only when
   its source scale is identified.

ZERO-FRAME CONTRACT
-------------------
1. A zero frame is rejected before ratio, baseline, domain, last-observed, or
   stabilization state can advance.
2. Repeated zero frames hold the last valid ratio.
3. The first recovered nonzero frame is baseline-only.
4. The runtime never writes current HP while observed HP is zero.
